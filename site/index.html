A keyboard-driven terminal for Indian markets.

Nivesh is a Bloomberg-style desktop app for NSE and BSE. Type a command, get a quote, a chart or a market view. Paper trading first.

Download for Mac Follow on GitHub →

Apple silicon (M1 and later). Unsigned for now, so read how to open it.

Type, don't click

Start typing anywhere and it goes to the command bar. The grammar is [EXCH:]TARGET [FUNCTION] [ARGS].

RELIANCE
Quote for NSE:RELIANCE
RELIANCE CH 5M 1MO
Candlestick chart: 5-minute bars, one month
ADD RSI 14
Add an indicator to the focused chart
MOV BANKNIFTY
Top gainers, losers and most active
SEC
Sector returns and a constituent heatmap
BT MYSTRAT RELIANCE 1D 1Y
Backtest a strategy on a year of daily bars
PAPER START MYSTRAT
Run a strategy with paper money
HELP
Every command and key

Where it is

Built in public, one part at a time. The plan lives in the repo.

  1. Done Terminal shell: panels, command bar, keymap, help
  2. Done Public market data: indices, quotes, instrument search
  3. Done Charts with indicators, movers, sectors, breadth and news
  4. Done Zerodha Kite connection: holdings, positions, orders, live ticks
  5. Done Strategies, backtests and paper trading
  6. Now Live trading behind risk limits, a kill switch and an audit log

Opening it the first time

The app isn't signed by Apple yet, so macOS will refuse to open it at first.

  1. Open the .dmg and drag Nivesh to Applications.
  2. In Finder, right-click (or Control-click) Nivesh, choose Open, then Open again in the dialog.
  3. If macOS says the app is damaged or can't be verified, run this in Terminal and open it again: 
    xattr -dr com.apple.quarantine /Applications/Nivesh.app
  4. On macOS 15 and later, if there's no Open option, go to System Settings → Privacy & Security and choose Open Anyway.

Paper trading is the default. Live trading is off at every start and has to be switched on by hand. Market data is public and may be delayed. Nothing here is investment advice.
